v0.7.5 preserves the deterministic Alignment Compiler and the working local Paratext connector, adds local Logos Desktop verse navigation, and simplifies the reviewer interface for smaller screens.

The duplicate Workspace sidebar has been removed. Use the tabs as the workspace navigator. The User Guide and keyboard shortcuts are under Help.

Your existing work is preserved

Installing v0.7.5 does not require a finished book or verse to be realigned. Human-approved work remains a HARD LOCK; completed historical work can remain PROTECTED LEGACY; partially worked verses preserve established groups; untouched verses remain OPEN.

Use Production → Existing Work Scan for a read-only compatibility report.

Alignment workflow

The toolbar follows the normal review sequence:

Connect | Unalign Target | Undo | Redo
Fill Alignment Gaps | Audit Existing Alignment | Apply AI Proposal
Save Alignment | Approve Verse | More…

Fill Alignment Gaps focuses AI on unresolved relationships while existing work remains protected context. Audit Existing Alignment is read-only. More… contains diagnostics, the larger alignment-groups viewer and backup restoration.

Deterministic Alignment Compiler

The compiler handles 1→1, 1→many, many→1 and many→many relationships, discontinuous groups, implicit source meaning and target-only grammatical material. Weak links cannot silently bridge strong components, and protected groups cannot be merged automatically. Strict validation remains independent of model behavior.

tN tW Review

The former AI Final Review workspace is now tN tW Review. AI prepares Translation Notes/Translation Words selections plus verse-level evidence; the human accepts, edits, discusses or rejects the proposal. AI-prepared content is not human-complete by itself.

Shortcuts remain discoverable in tooltips: F5 prepare review, F8 next priority, Ctrl+Enter Accept, Ctrl+Shift+D Discussion, Ctrl+Shift+R Reject AI, Ctrl+Shift+Right Next Verse.

Paratext Live Connector

The v0.7.4 local connector remains in place. Close Paratext before installing/updating the companion plugin, then restart Paratext, open the intended project, place its Scripture window in scroll/sync group A–E, and use Production → Paratext → Connect / Refresh.

Use Verify / Bind Project before live navigation or notes. Project binding prevents notes/navigation from being sent to the wrong Paratext project. Live Project Notes are authored by the actual Paratext user; AI provenance remains separate.

Logos Live Verse Navigation

Start Logos Desktop, then use Production → Logos → Connect / Refresh. The Bridge talks to Logos through the locally registered Windows COM API. No Logos username, password or API key is stored by the Bridge.

Enable Sync verse navigation explicitly. Logos synchronization starts off each Bridge session. The connector is navigation-only and has no Scripture-write function.

Any-direction navigation

Bridge ↔ Navigation Broker ↔ Paratext
                    ↕
                   Logos

A reference can originate in the Bridge, Paratext or Logos. The Navigation Broker suppresses recent echoes and unchanged polls, then forwards the accepted reference only to the other enabled connectors. Rapid Logos-bound changes are coalesced so the latest requested verse wins.

If Logos moves to a book for which no translationCore project is loaded, the Bridge does not guess. Unsaved alignment edits continue to receive the existing discard confirmation before external navigation can replace the verse.

Production workspace

Production sections are collapsible and the whole page scrolls vertically. On smaller screens its two columns stack into one. It contains crash recovery, Git, team/reviewer workflow, Paratext, Logos, metrics and language/plugin status.

The Dashboard now keeps the exception queue and selected exception summary side-by-side with a draggable divider; the details pane has vertical scrolling.

Settings & Log

All sections are collapsible and vertically scrollable. The OpenAI API section displays Bridge-recorded lifetime tokens and accumulated estimated cost. These are observations recorded by this Bridge settings profile, not an OpenAI account billing statement.

Tooltips are screen-aware: near the right or bottom edge they flip/clamp inside the visible monitor work area rather than extending off-screen.

Certification

The portable v0.7.5 package discovers 173 tests in the current build environment. All runnable tests pass; backend-dependent tests are skipped when the real translationCore/Windows environment is unavailable.

Run certify_windows.bat "C:\path\to\translationCore" on Windows. Certification must use a disposable clone for write-capable project tests. Paratext 9.5.110.1 and the installed Logos Desktop COM interface require separate real-Windows field tests before claiming full connector certification.
