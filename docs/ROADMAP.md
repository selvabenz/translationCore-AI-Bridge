# Roadmap after v0.7.0

v0.7.0 implements the requested production foundations. The following are **future enhancements**, not missing items from the v0.7.0 production list:

- code-signing/SmartScreen reputation for the distributed Windows installer;
- optional Qt/web presentation shell while retaining the tested Python/tC engine;
- organization-specific authentication/central reviewer directory for multi-machine teams;
- consultant-configurable publication gates and approval stages;
- additional target-language plugins (Hindi, Malayalam, Telugu, etc.);
- richer UGNT/Greek workflows;
- deeper Psalms structure integration with the separate Psalms Editor dataset;
- optional local/on-prem model backends if organizational policy later requires them;
- benchmarking against a measured manual translationCore review baseline to quantify actual time saved.

These enhancements should preserve the v0.7.0 rule: AI prepares and explains; humans decide and approve.
