## Source of truth
- `official-app-logo-source.png` - original supplied artwork.
- `app_icon.png` - normalized application PNG.
- `app_icon_48.png` - title-bar/UI icon.
- `app_icon.ico` - multi-resolution Windows executable/installer icon.

For a future app release, copy these generated assets into the application's `assets/` directory (or run its `set_app_icon.bat` workflow), then rebuild the PyInstaller EXE and Inno Setup installer.
