# translationCore AI Bridge - Product Documentation

Detailed GitHub Pages-ready product manual with actual application screenshots.

## Open locally
Open `index.html` in a browser.

## GitHub Pages
Commit this folder to a repository. The included workflow publishes the documentation directory as a static Pages artifact.

## Branding
`brand/` contains the official future-release logo supplied on 13 August 2026 and generated Windows/UI icon assets.

## Screenshot provenance
Screenshots are captured from the actual v0.6.6 Tk desktop application against real Ruth/Psalms translationCore data. The populated AI Final Review screenshot uses deterministic illustrative AI output to avoid a real paid API request.
